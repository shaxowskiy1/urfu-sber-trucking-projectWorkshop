Проект: Logistics Management System (frontend)

Общее назначение:
- Веб-приложение на React (Vite + SWC), панели для логиста и грузоотправителя, работа с заказами и автопарком.

Корень проекта:
- index.html — HTML-шаблон приложения.
- package.json — зависимости, скрипты сборки/запуска фронтенда.
- vite.config.ts — конфигурация Vite, алиасы и dev-сервер.
- README.md — общее описание проекта.
- PROJECT_STRUCTURE.txt — этот файл: обзор структуры и назначение файлов.
- backend-test/ — мок-бэкенд на Express + SQLite для локальной проверки API.
  - server.js — HTTP-сервер, маршруты /api/* (заказы, водители, и т.д.).
  - database.js — инициализация SQLite и CRUD-слои для сущностей.
  - package.json — зависимости и скрипт запуска мок-бэкенда.
  - DATABASE_ISSUE_EXPLANATION.md, readme.md — пояснения по БД/бэкенду.

Папка src/ — исходники фронтенда
- main.tsx — точка входа React.
- App.tsx — корневой компонент приложения.
- index.css — базовые стили.
- styles/globals.css — глобальные стили Tailwind/пользовательские стили.
- utils/orderStatusStyles.ts — отображение стилей статуса заказа.
- services/ — API-клиенты к бэкенду/внешним источникам
  - orderApi.ts — запросы для создания/обновления заказов.
  - driverApi.ts — (теперь без автоподгрузки при создании) функции загрузки водителей из внешнего API.
  - assignmentApi.ts, calculateApi.ts — вспомогательные/примерные API.
- guidelines/ — внутренние руководства.
- Документация: API_EXAMPLES.md, API_INTEGRATION.md, COMMENTS_LOGIC.md, DATABASE_SCHEMA.md, ER_DIAGRAM.md, QUICK_START.md, Attributions.md.

Папка src/components — UI и бизнес-компоненты (детализировано по каждому файлу):

[Корень components]
- AddOrderModal.tsx — модальное окно создания нового заказа; рендерит форму `OrderForm` и отправляет данные на бэкенд.
- AddressInput.tsx — инпут адреса с поддержкой координат (lat/lng) и валидации.
- ApiDataPreview.tsx — предпросмотр данных, загружаемых из внешних API (диагностика/демо).
- ApiInstructions.tsx — инструктивный блок с примерами URL/ответов внешнего API.
- ApiStatusIndicator.tsx — компактный индикатор последней загрузки данных (кол-во, время, дубликаты).
- AuthForm.tsx — форма авторизации и регистрации пользователей.
- CommentModal.tsx — модал для добавления/редактирования комментариев (компания/менеджер/заказ).
- CompanyOrdersModal.tsx — модал со всеми заказами по компании или менеджеру.
- FleetManagement.tsx — управление автопарком: водители, тягачи, прицепы, связки; формы добавления и редактирования.
- LogisticianDashboard.tsx — панель логиста: статистика, таблица заказов, создание заказа, доступ к автопарку. (Автоподгрузка водителей при создании заказа удалена.)
- OrderConfirmationModal.tsx — подтверждение создания заказа перед отправкой.
- OrderDetailModal.tsx — подробности заказа, смена статуса, назначение водителя, удаление.
- OrderForm.tsx — многошаговая форма/форма с полями для создания заказа, валидация и сбор данных.
- OrderSuccessModal.tsx — уведомление об успешном создании заказа.
- OrderTable.tsx — таблица заказов: список, фильтрация, действия.
- PassForm.tsx — форма пропусков/допусков (если используется в логике пропуска на объект).
- ShipperDashboard.tsx — панель грузоотправителя: его заказы и действия.
- ShipperOrdersModal.tsx — модал со списком заказов конкретного грузоотправителя.

Примечания:
- Создание заказа: теперь при нажатии кнопки сразу открывается модал `AddOrderModal` без каких-либо запросов к внешним API.
- Для работы с серверной частью используйте локальный мок-бэкенд из `backend-test/` (порт 3001) или задавайте `VITE_API_BASE_URL` при необходимости.
