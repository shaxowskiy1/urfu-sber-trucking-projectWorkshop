# Smart Logistics

**Smart Logistics** — простая TMS‑система для малых логистических компаний со своим автопарком, выполняющих в основном короткие рейсы и получающих много заказов «по телефону». Основная идея продукта — превратить ведомость логиста в удобный веб‑сервис, который ускоряет работу и убирает рутину.

## Что делает приложение

Приложение позволяет логисту:

- фиксировать все заказы в единой системе (в том числе полученные по телефону или импортированные с биржи грузоперевозок);
- отслеживать статусы выполнения заказов и рейсов;
- подбирать транспорт под заказ, используя рекомендательный алгоритм (с учётом доступности и параметров машин);
- автоматически формировать пропуска (автозаявки);
- в перспективе — выгружать данные по заказам во внешние системы (1С, Битрикс, Excel) через REST API и/или подготовленные отчёты.

## Цель продукта

Цель продукта — сократить время на обработку одного заказа, ускорить повседневные процессы логиста и обеспечить хранение всей информации о заказах и их статусах в одном месте.

## Основные возможности

- Учет заказов.
- Подбор транспорта на заказ.
- Автоматическое формирование автозаявок (пропусков) на объекты с отправкой на электронную почту.
- В перспективе:
  - формирование плана рейсов на день;
  - выгрузка данных:
    - вручную (Excel‑отчёты по шаблонам: «список рейсов за месяц», «заказы по клиенту» и т.п.);
    - программно (REST API + webhooks по событиям) для интеграции с 1С/Битрикс и другими системами.

## Для кого

- Малые логистические компании со своим парком (примерно до 20–30 машин).
- Компании, которые:
  - работают в малом радиусе;
  - имеют в среднем 1–2 заказа на машину в день;
  - получают много заказов по телефону и хотят перестать вести всё в Excel/тетрадях.
